# Imagens das famílias botânicas

Imagens para praticar o carregamento de imagens (Script 09).

## Características

- Formato: JPG, PNG ou WebP.
- Tamanho: até 2 MB.
- Largura: pelo menos 800 px (recomendado: 1600 × 900, formato 16:9).
- Nome do ficheiro: o slug da família (ex.: `araceae.jpg`).
- Licença: imagens de utilização livre (ex.: Wikimedia Commons, Unsplash, Pexels).
